1. Connect your reader

Use desktop Chrome or Edge and a USB-C data cable. Close any serial monitor or other flasher before connecting.

Select your reader’s USB serial port when prompted. If the connection fails, put the reader in download mode using its recovery instructions, then reconnect.

2. Install BuddyPoint

The included build has BuddySync, custom themes, Sudoku, and the Markdown viewer.

Installs the bootloader, partition table, and application, and resets the boot selection. The SD card is untouched. Custom files must use this project’s 16 MB partition layout; factory images are not accepted here.
