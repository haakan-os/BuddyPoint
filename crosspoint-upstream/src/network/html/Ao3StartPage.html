AO3 account

  1. On your reader, use File Transfer → Join a Network. Hotspot mode has no AO3 internet connection.
  2. Press Confirm / AO3 on the reader's File Transfer screen to enable the secure account panel.
  3. Open the https://…:8443/ address shown on the reader. Inspect the browser's certificate details and compare its SHA-256 fingerprint with the reader before accepting the local certificate.
  4. Enter the eight-digit pairing code, then sign in to AO3.

The secure panel lets you download private bookmarks, update fics and forget the saved account. Keep File Transfer open during jobs. This HTTP page never asks for your AO3 password.
